# variables_if_else_while

This project introduces the basics of C: variables, arithmetic,
relational and logical operators, `if` / `else` statements and
`while` loops.

## Files

- `0-positive_or_negative.c`: prints whether a random number is
  positive, zero or negative
- `1-last_digit.c`: prints the last digit of a random number and
  compares it to 0 and 5
- `2-print_alphabet.c`: prints the alphabet in lowercase using putchar
- `3-print_alphabets.c`: prints the alphabet in lowercase, then in
  uppercase, using putchar
- `4-print_alphabt.c`: prints the lowercase alphabet without the
  letters q and e, using putchar

  starting from 0.#....
- `6-print_numberz.c`: prints all single digit numbers of base 10,
  starting from 0, using only putchar and no char variable
- `7-print_tebahpla.c`: prints the lowercase alphabet in reverse,
  using putchar
- `8-print_base16.c`: prints all the numbers of base 16 in lowercase,
